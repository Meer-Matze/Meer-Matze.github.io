# 图的表示

下文默认使用有向图，顶点编号为 $0$ 到 $V-1$。无向边 $(u,v)$ 需要存储为两条有向边：$u\to v$ 和 $v\to u$。

## 复杂度概览

| 表示方式   | 空间复杂度 | 查询边 $(u,v)$ | 遍历顶点 $u$ 的邻接点 |
| ---------- | ---------- | -------------- | --------------------- |
| 邻接矩阵   | $O(V^2)$   | $O(1)$         | $O(V)$                |
| 邻接表     | $O(V+E)$   | $O(\deg^+(u))$ | $O(\deg^+(u))$        |
| 链式前向星 | $O(V+E)$   | $O(\deg^+(u))$ | $O(\deg^+(u))$        |

## 邻接矩阵

```cpp
struct GraphAdjMatrix {
    int vertex_count; // 顶点数
    int edge_count = 0;   // 边数
    std::vector<std::vector<int>> adj_matrix; // 邻接矩阵

    GraphAdjMatrix(int v) : vertex_count(v), adj_matrix(v, std::vector<int>(v, 0)) {}

    void addEdge(int u, int v) {
        if (adj_matrix[u][v] == 0) {
            adj_matrix[u][v] = 1;
            edge_count++;
        }
    }
};
```

## 邻接表

```cpp
struct GraphAdjList {
    int vertex_count; // 顶点数
    int edge_count = 0;   // 边数
    std::vector<std::vector<int>> adj_list; // 邻接表

    GraphAdjList(int v) : vertex_count(v), edge_count(0), adj_list(v) {}

    void addEdge(int u, int v) {
        adj_list[u].push_back(v);
        edge_count++;
    }
};
```

### 链式前向星

链式前向星使用数组模拟邻接表，适合需要高效遍历边的场景。`head[u]` 指向顶点 $u$ 的第一条边，`next` 把同一出发点的边串起来。

```cpp
struct GraphForwardStar {
    int vertex_count; // 顶点数
    int edge_count = 0;   // 边数

    struct Edge {
        int to;     // 终点
        int next;   // 下一条边的索引
    };
    std::vector<Edge> edges; // 边数组
    std::vector<int> head;   // 顶点的第一条边的索引

    GraphForwardStar(int v) : vertex_count(v), edges(), head(v, -1) {}

    void addEdge(int u, int v) {
        edges.push_back({v, head[u]});
        head[u] = edge_count;


        edge_count++;
    }

    GraphForwardStar transpose() const {
        GraphForwardStar result(vertex_count);
        for (int u = 0; u < vertex_count; u++) {
            for (int i = head[u]; i != -1; i = edges[i].next) {
                result.addEdge(edges[i].to, u);
            }
        }
        return result;
    }

};
```

边会以“后加入的边优先”的顺序遍历。若需要无向图，调用 `addEdge(u, v)` 和 `addEdge(v, u)` 各一次。

# 广度优先搜索（BFS）

广度优先搜索（Breadth-First Search，BFS）按距离起点的层数访问顶点。对于无权图，BFS 第一次到达顶点时得到的路径边数最少。

```cpp
std::vector<int> bfs(const GraphForwardStar& graph, int start) {
    std::vector<bool> visited(graph.vertex_count, false);
    std::queue<int> q;
    std::vector<int> order;

    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);

        for (int i = graph.head[u]; i != -1; i = graph.edges[i].next) {
            int v = graph.edges[i].to;
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
    return order;
}

```

把顶点加入队列时就标记，而不是出队时标记，可以避免同一顶点被重复加入队列。若只需要访问从 `start` 可达的顶点，上述实现已经足够；若要遍历整个图，需要从每个未访问顶点重新启动 BFS。

# 深度优先搜索（DFS）

深度优先搜索（Depth-First Search，DFS）沿一条路径尽可能深入，再回溯处理其他分支。它常用于环检测、拓扑排序和强连通分量。

下面的实现使用了 `std::function`，因此需要包含 `<functional>` 头文件。

```cpp
// state[u]：0 表示未访问，1 表示正在访问，2 表示已完成
bool traverseDfs(
    const GraphForwardStar& graph, int start, std::vector<int>& state,
    const std::function<void(int)>& onEnter,
    const std::function<void(int)>& onExit,
    const std::function<bool(int, int)>& onEdge) {
    if (state[start] != 0) {
        return true;
    }

    std::stack<std::pair<int, int>> stack;
    state[start] = 1;
    onEnter(start);
    stack.push({start, graph.head[start]});

    while (!stack.empty()) {
        int u = stack.top().first;
        int& edge_index = stack.top().second;

        if (edge_index == -1) {
            state[u] = 2;
            onExit(u);
            stack.pop();
            continue;
        }

        int edge = edge_index;
        edge_index = graph.edges[edge].next;
        int v = graph.edges[edge].to;
        if (!onEdge(u, v)) {
            return false;
        }

        if (state[v] == 0) {
            state[v] = 1;
            onEnter(v);
            stack.push({v, graph.head[v]});
        }
    }
    return true;
}

std::vector<int> dfs(const GraphForwardStar& graph, int start,
                     std::vector<int>& state) {
    std::vector<int> order;
    traverseDfs(
        graph, start, state,
        [&](int u) { order.push_back(u); },
        [](int) {},
        [](int, int) { return true; });
    return order;
}

std::vector<int> dfs(const GraphForwardStar& graph, int start) {
    std::vector<int> state(graph.vertex_count, 0);
    return dfs(graph, start, state);
}
```

`traverseDfs` 用三个回调暴露 DFS 事件：进入顶点时调用 `onEnter`，处理完所有出边时调用 `onExit`，处理每条边时调用 `onEdge`。整个实现使用显式栈，不使用函数调用栈。

# 拓扑排序

拓扑排序（topological sort）只适用于有向无环图（DAG）。它把所有顶点排列成一个序列，使每条边 $u\to v$ 都满足 $u$ 出现在 $v$ 之前。

## Kahn 算法

Kahn 算法反复删除入度为 $0$ 的顶点，并把它加入结果序列。删除顶点时，所有出边指向顶点的入度减一。

```cpp
std::vector<int> topologicalSort(const GraphForwardStar& graph) {
    std::vector<int> indegree(graph.vertex_count, 0);
    for (const auto& edge : graph.edges) {
        indegree[edge.to]++;
    }

    std::queue<int> q;
    for (int u = 0; u < graph.vertex_count; u++) {
        if (indegree[u] == 0) {
            q.push(u);
        }
    }

    std::vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);

        for (int i = graph.head[u]; i != -1; i = graph.edges[i].next) {
            int v = graph.edges[i].to;
            if (--indegree[v] == 0) {
                q.push(v);
            }
        }
    }

    if (static_cast<int>(order.size()) != graph.vertex_count) {
        return {}; // 图中存在环
    }
    return order;
}
```

算法时间复杂度为 $O(V+E)$。若最终序列的长度小于 $V$，说明仍有顶点的入度无法降为 $0$，因此图中存在环，不能进行拓扑排序。

> [!note] 拓扑序不唯一
> 当队列中同时存在多个入度为 $0$ 的顶点时，选择顺序不同会得到不同的合法拓扑序。

## DFS 后序法

DFS 也可以通过后序排列得到拓扑序：顶点的所有出邻接点处理完后，再把顶点加入结果。最后将结果反转。若在 DFS 中遇到“指向当前 DFS 路径上的顶点”的边，则图中存在环。

```cpp
std::vector<int> topologicalSortByDfs(const GraphForwardStar& graph) {
    std::vector<int> state(graph.vertex_count, 0);
    std::vector<int> order;

    // 每个未访问顶点都可能是一个独立连通分量的起点
    for (int u = 0; u < graph.vertex_count; u++) {
        bool valid = traverseDfs(
            graph, u, state,
            [](int) {},
            [&](int current) { order.push_back(current); },
            [&](int, int next) { return state[next] != 1; });
        if (!valid) {
            return {}; // 图中存在环
        }
    }

    std::reverse(order.begin(), order.end());
    return order;
}
```

外层循环解决了多个独立起点的问题。它不是人为选择一个“全图起点”，而是保证每个顶点最终都被处理。`state[u] == 1` 表示顶点仍在当前 DFS 路径中，此时再次遇到它就说明存在环。

前面的普通 DFS 返回的是前序访问顺序，不能直接用于拓扑排序。拓扑排序必须在顶点的所有后继顶点处理完之后再记录它，也就是使用后序顺序，最后再整体反转。

# 强连通分量

在有向图中，如果顶点 $u$ 可以到达 $v$，并且 $v$ 也可以到达 $u$，则称 $u$ 和 $v$ 强连通。一个极大的强连通顶点集合称为强连通分量（Strongly Connected Component，SCC）。

## Kosaraju 算法

Kosaraju 算法需要两次 DFS：

1. 在原图上进行 DFS，按完成时间从早到晚记录顶点。
2. 反转所有边。
3. 构造转置图，并按完成时间从晚到早在转置图上 DFS。每次 DFS 访问到的顶点就是一个 SCC。

```cpp
std::vector<int> finishOrder(const GraphForwardStar& graph, int start,
                             std::vector<int>& state) {
    std::vector<int> order;
    traverseDfs(
        graph, start, state,
        [](int) {},
        [&](int u) { order.push_back(u); },
        [](int, int) { return true; });
    return order;
}

std::vector<std::vector<int>> stronglyConnectedComponents(
    const GraphForwardStar& graph) {
    std::vector<int> state(graph.vertex_count, 0);
    std::vector<int> order;
    for (int u = 0; u < graph.vertex_count; u++) {
        if (state[u] == 0) {
            std::vector<int> current_order = finishOrder(graph, u, state);
            order.insert(order.end(), current_order.begin(), current_order.end());
        }
    }

    GraphForwardStar transposed = graph.transpose();
    state.assign(graph.vertex_count, 0);
    std::vector<std::vector<int>> components;
    for (auto it = order.rbegin(); it != order.rend(); ++it) {
        if (state[*it] == 0) {
            components.push_back(dfs(transposed, *it, state));
        }
    }
    return components;
}
```

`transpose()` 将原图中的每条边 `u -> v` 反转为 `v -> u`。Kosaraju 算法的时间复杂度为 $O(V+E)$，空间复杂度为 $O(V+E)$。第二遍 DFS 直接复用前面的 `dfs(graph, start, visited)`，只是在转置图上运行。

> [!warning] SCC 与连通分量不同
> 无向图讨论的是连通分量；有向图中的 SCC 要求两个方向都存在可达路径。把有向边当作无向边处理，会丢失方向信息。
