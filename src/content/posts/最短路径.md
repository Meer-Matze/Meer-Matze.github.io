在带权有向图 $G=(V,E)$ 中，给定源点 $s$，求 $s$ 到其余各点的最短路径长度（单源最短路径，SSSP）；或求任意两点间的最短路径长度（多源最短路径，APSP）。边权可为正、负，但**不允许存在负权环**（否则最短路无定义）。

记 $|V|=n$，$|E|=m$。

# 单源最短路径（SSSP）算法

## Bellman-Ford 算法

Bellman-Ford 算法用于**单源最短路径**，支持**负权边**，并能**检测负权环**（总权值为负的环，可无限绕圈让路径长度趋向 $-\infty$，导致最短路无定义）。核心思想是**边松弛**（若 $dist[v] > dist[u] + w$ 则更新 $dist[v] = dist[u] + w$，即“发现更短路就拉短距离估计”）：对所有边执行 $n-1$ 轮松弛，第 $n$ 轮若仍能松弛则存在负权环。

### 算法原理

最短路至多包含 $n-1$ 条边。对所有边执行 $n-1$ 次松弛：

$$
\text{if } dist[v] > dist[u] + w(u,v) \text{ then } dist[v] = dist[u] + w(u,v)
$$

第 $n$ 次松弛若仍有更新，说明存在从源点可达的负权环。

### 实现步骤

1. 初始化 $dist[s]=0$，其余 $=\infty$。
2. 重复 $n-1$ 次：遍历所有边，执行松弛。
3. 第 $n$ 次遍历：若仍有边可松弛，标记其终点为“受负环影响”。
4. （可选）记录前驱节点 $prev[v]$，便于生成最短路径。

### 复杂度

- 时间：$O(nm)$
- 空间：$O(n+m)$

### 优化：SPFA（Shortest Path Faster Algorithm）

SPFA 是 Bellman-Ford 的队列优化版本，**仅将“距离被更新的点”入队**，平均时间复杂度 $O(m)$，最坏仍为 $O(nm)$。

实现步骤：

1. 初始化 $dist[s]=0$，其余 $=\infty$，将源点入队。
2. - 当队列非空：
     - 弹出队首点 $u$，对其所有出边 $(u,v,w)$ 执行松弛。
     - 若 $dist[v]$ 被更新且 $v$ 不在队列中，则将 $v$ 入队。
   - 若队列为空，结束。
   - 若某点入队次数超过 $n$，说明存在负权环。

### P3385 负环

```cpp
#include <iostream>
#include <vector>
#include <queue>

constexpr long long INF = 4e18;

struct Edge {
    int to, next, weight;
};

int edge_count;
std::vector<Edge> edges;
std::vector<int> first_edges;

void addEdge(const int u, const int v, const int w) {
    edges[edge_count] = {.to = v, .next = first_edges[u], .weight = w};
    first_edges[u] = edge_count++;
}

int main() {
    int t, n, m;
    std::cin >> t;
    while (t--) {
        std::cin >> n >> m;
        edges.resize(2 * m + 1);
        first_edges.assign(n + 1, -1);
        edge_count = 0;
        for (int i = 0; i < m; i++) {
            int u, v, w;
            std::cin >> u >> v >> w;
            if (w >= 0) {
                addEdge(v, u, w);
                addEdge(u, v, w);
            }
            else
                addEdge(u, v, w);
        }

        /* 初始化 */
        std::vector<long long> dis(n + 1, INF);
        std::vector<int> push_count(n + 1, 0);
        std::vector<bool> in_queue(n + 1, false);
        std::queue<int> q;
        dis[1] = 0;
        q.push(1);
        in_queue[1] = true;
        push_count[1] = 1; // 源点入队也算入队次数
        bool hasCycle = false;

        /* spfa */
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            in_queue[u] = false;
            for (int e = first_edges[u]; e != -1; e = edges[e].next) {  //遍历出边，松弛
                int v = edges[e].to;
                if (dis[v] > dis[u] + edges[e].weight) {
                    dis[v] = dis[u] + edges[e].weight;
                    if (!in_queue[v]) { // 不在队列中才入队
                        q.push(v);
                        in_queue[v] = true;
                        push_count[v]++;
                        if (push_count[v] >= n) { // 同一结点入队 n 次 -> 负环
                            hasCycle = true;
                            break;
                        }
                    }
                }
            }
            if (hasCycle) break;
        }

        /* 输出 */
        std::cout << (hasCycle ? "YES\n" : "NO\n");
    }
}
```

## Dijkstra 算法

Dijkstra 算法是**非负权边**单源最短路径的**贪心**算法。每次从“未确定最短距离的点”中取出距离最小的点，确定其最短距离，并用它**松弛**出边（若 $dist[v] > dist[u] + w$ 则更新 $dist[v] = dist[u] + w$）。正确性依赖于**非负权边**：一旦 $u$ 被取出，其 $dist[u]$ 不会再被更短路径更新；**遇负权环直接失效**（贪心性质不再成立）。

### 算法原理

维护集合 $S$（已确定最短距离的点）。每步从 $V \setminus S$ 中取 $dist$ 最小的点 $u$ 加入 $S$，对 $u$ 的出边松弛。

### 实现方式与复杂度对比

| 实现方式            | extract-min      | decrease-key / 松弛方式    | 总复杂度          | 适用场景                  |
| ------------------- | ---------------- | -------------------------- | ----------------- | ------------------------- |
| 邻接矩阵 + 线性扫描 | $O(n)$           | $O(1)$ 直接改数组          | $O(n^2)$          | 稠密图（$m \approx n^2$） |
| 邻接表 + 二叉堆     | $O(\log n)$      | 惰性删除（重复入堆）       | $O(m \log n)$     | 稀疏图，通用首选          |
| 邻接表 + 斐波那契堆 | $O(\log n)$ 均摊 | $O(1)$ 均摊真 decrease-key | $O(m + n \log n)$ | 理论最优，工程少用        |

> [!warning]
> C++ `priority_queue` 无原生 decrease-key，常用**惰性删除**——松弛时直接 `push` 新记录，取出时若该点已访问则 `continue`（堆里会有同一顶点的多条记录，旧的大距离留在堆里，弹出时丢弃）。堆大小 $O(m)$，复杂度 $O(m \log m) = O(m \log n)$。

### 链式前向星 + 最小堆（P4779 单源最短路径）

```cpp
#include <iostream>
#include <vector>
#include <queue>

constexpr long long INF = 4e18;

using Pair = std::pair<long long, int>;  // 优先队列里的元素：{dist, vertex}

struct Edge {
    int to;           // 这条边通向哪个顶点
    int next;         // 同一个顶点的链表中，下一条边的编号
    long long weight; // 这条边的权
};

int main() {

    // ---------- 1. 读入图的规模，以及源点 ----------
    int n, m, s;
    std::cin >> n >> m >> s;

    // ---------- 2. 用链式前向星建图 ----------
    std::vector<int> firstEdge(n + 1, -1);   // 顶点编号是 1,\,\ldots,\,n
    std::vector<Edge> edges(m + 1);             // 边编号从 0 开始，最多 m 条
    int edgeCount = 0;                            // 当前已经存了多少条边

    // 在顶点 u 的链表头部插入一条新边：u -> v，权值 w
    auto addEdge = [&](const int u, const int v, const long long w) {
        // 注意：结构体的字段顺序按声明顺序写，next 填的是 u 原来的第一条边，
        // 这样新边就成为了链表新的头部。
        edges[edgeCount] = {.to = v, .next = firstEdge[u], .weight = w};
        firstEdge[u] = edgeCount;  // 更新 u 的第一条边为新插入的这条
        ++edgeCount;               // 预留下一个边的编号
    };

    for (int i = 0; i < m; i++) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        addEdge(u, v, w);
    }

    // ---------- 3. 初始化距离和访问标记 ----------
    std::vector<long long> dist(n + 1, INF);  // dist[x] = 源点 s 到 x 的最短距离
    std::vector<bool> vis(n + 1, false);      // vis[x] = x 的最短距离是否已确定
    std::priority_queue<Pair, std::vector<Pair>, std::greater<>> pq;  // 最小堆

    dist[s] = 0;       // 源点到自己的距离是 0
    pq.emplace(0, s);  // 源点入队

    // ---------- 4. Dijkstra 主循环：每次取出当前最近的未确定顶点 ----------
    while (!pq.empty()) {
        // 堆顶是当前离源点最近的点：元组里分别是距离 d 和顶点编号 u
        auto [d, u] = pq.top();
        pq.pop();

        // 同一个顶点可能被重复入队（中间值），vis 标记后只处理第一次出队，
        // 后面再弹出的就是过时记录了，直接跳过（惰性删除：不主动删旧记录，取出时再丢弃）。
        if (vis[u]) continue;
        vis[u] = true;  // 此时 d 就是 u 的真正最短距离，标记它已确定

        // 遍历 u 的所有出边（顺着 firstEdge 链下去）
        for (int e = firstEdge[u]; e != -1; e = edges[e].next) {
            const Edge& edge = edges[e];  // 拿到当前这条边

            // 如果 u 的终点 v 还没确定最短路，且经过 u 能走得更近，就更新 v 的距离（松弛）
            if (!vis[edge.to] && dist[edge.to] > d + edge.weight) {
                dist[edge.to] = d + edge.weight;
                pq.emplace(dist[edge.to], edge.to);  // 新距离入堆，等待被取出
            }
        }
    }

    // ---------- 5. 输出结果 ----------
    for (int i = 1; i <= n; i++) {
        std::cout << dist[i] << ' ';
    }
}
```

# 多源最短路径（APSP）算法

## Floyd-Warshall 算法

Floyd-Warshall 算法是一种**动态规划**算法，用于求解**所有点对最短路径**（APSP）。它的核心思想是：逐步允许使用编号为 $1,\,\ldots,\,k$ 的点作为中间点，更新任意两点间的最短距离。

### 算法原理

设 $dist[i][j]^{(k)}$ 表示只允许使用 $\{1,2,\dots,k\}$ 作为中间点时，$i$ 到 $j$ 的最短距离。则有递推式：

$$
dist[i][j]^{(k)} = \min\bigl(dist[i][j]^{(k-1)},\; dist[i][k]^{(k-1)} + dist[k][j]^{(k-1)}\bigr)
$$

$dist[i][j]^{(0)}$ 为 $i\rightarrow j$ 的边权（无边设为 $\infty$，自环为 $0$）。最终 $dist[i][j]^{(n)}$ 即为答案。

### 实现步骤

1. 初始化 $n \times n$ 距离矩阵：$dist[i][j] = w(i,j)$（无边设 $\infty$，$i=j$ 设 $0$）。
2. 三重循环 $k=1,\,\ldots,\,n,\;i=1,\,\ldots,\,n,\;j=1,\,\ldots,\,n$，执行**松弛**操作
   - 松弛：若 $dist[i][j] > dist[i][k] + dist[k][j]$，则更新 $dist[i][j] = dist[i][k] + dist[k][j]$。
3. （可选）记录前驱节点 $prev[i][j]$ 为路径 $ i \rightarrow j $ 上 $j$ 的前一个节点，便于生成最短路径。
   - 若 $dist[i][j]$ 被更新，则 $prev[i][j] = prev[k][j]$。

### 复杂度

- 时间：$O(n^3)$
- 空间：$O(n^2)$（可压缩为原地更新）

### P2910 [USACO08OPEN] Clear And Present Danger S

农夫约翰正驾驶一条小艇在牛勒比海上航行。

海上有 $N(1\leq N\leq 100)$ 个岛屿，用 $1$ 到 $N$ 编号。约翰从 $1$ 号小岛出发，最后到达 $N$ 号小岛。

一张藏宝图上说，如果他的路程上经过的小岛依次出现了 $A_1,A_2,\dots ,A_M(2\leq M\leq 10000)$ 这样的序列（不一定相邻），那他最终就能找到古老的宝藏。但是，由于牛勒比海有海盗出没，约翰知道任意两个岛屿之间的航线上海盗出没的概率，他用一个危险指数 $D_{i,j}(0\leq D_{i,j}\leq 100000)$ 来描述。他希望他的寻宝活动经过的航线危险指数之和最小。那么，在找到宝藏的前提下，这个最小的危险指数是多少呢？

**输入格式**：

第一行：两个用空格隔开的正整数 $N$ 和 $M$。

第二到第 $M+1$ 行：第 $i+1$ 行用一个整数 $A_i$ 表示 FJ 必须依次经过的第 $i$ 个岛屿。保证 $A_1=1,A_M=N$。

第 $M+2$ 到第 $N+M+1$ 行：第 $i+M+1$ 行包含 $N$ 个用空格隔开的非负整数分别表示 $i$ 号小岛到第 $1\dots N$ 号小岛的航线各自的危险指数。保证第 $i$ 个数是 $0$。

**输出格式**：

第一行：FJ 在找到宝藏的前提下经过的航线的危险指数之和的最小值。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

constexpr long long INF = 4e18;

using  AdjMatrix = std::vector<std::vector<long long>>;

void floyd(AdjMatrix& distant, int dist_len);

int main() {

    int n, m;
    std::cin >> n >> m;

    std::vector<int> passing_islands(m);

    for (int i = 0; i < m; i++) {
        std::cin >> passing_islands[i];
    }

    /* 初始化距离矩阵 */
    AdjMatrix dist(n + 1, std::vector<long long>(n + 1, INF));
    // 由于数据保证了 D_{i,i} = 0，就不用手动设置了

    for (int from = 1; from <= n; from++) {
        long long w;
        for (int to = 1; to <= n; to++) {
            std::cin >> w;
            dist[from][to] = std::min(dist[from][to], w);  // 可能有重边，取最小
        }
    }

    /* 计算任意两点间的最短距离 */
    floyd(dist, n);

    /**
     * 数据保证没有负权环，所以不需要检测负环。
     * 不过这里还是讲一下，
     * 如果 dist[i][i] < 0，则说明存在负权环。
    **/

    /* 输出最短距离 */
    long long min_danger = 0;
    for (int i = 0; i < m - 1; i++) {
        const int u = passing_islands[i], v = passing_islands[i + 1];
        min_danger += dist[u][v];
    }
    std::cout << min_danger << '\n';

    return 0;
}

/* Floyd-Warshall 核心三重循环 */
void floyd(AdjMatrix& distant, const int dist_len) {

    for (int k = 1; k <= dist_len; k++) {
        for (int i = 1; i <= dist_len; i++) {
            if (distant[i][k] == INF) continue;  // 微优化：不可达则跳过
            for (int j = 1; j <= dist_len; j++) {
                if (distant[k][j] == INF) continue;
                if (distant[i][j] > distant[i][k] + distant[k][j]) { // 松弛
                    distant[i][j] = distant[i][k] + distant[k][j];
                }
            }
        }
    }
}
```

## Johnson 算法

Johnson 算法用于**稀疏图的所有点对最短路径（APSP）**。核心思想：**重新加权**消除负权边，然后对每个点跑一次 Dijkstra。

### 算法步骤

1. **添加虚拟源点** $s'$，向所有点连权为 $0$ 的边。
2. 跑 **Bellman-Ford** 从 $s'$ 求 $h[v] = \delta(s', v)$。若有**负权环**（总权值为负的环，可无限绕圈让路径长度趋向 $-\infty$），直接报告。
3. **重新加权**：每条边 $(u,v,w)$ 新权重 $w' = w + h[u] - h[v]$。可证 $w' \ge 0$，且任意路径长度仅相差常数 $h[t]-h[s]$，最短路结构不变。
4. 对每个点 $u=1,\,\ldots,\,n$，跑 **Dijkstra**（用 $w'$）求 $dist'[u][v]$。
5. **还原真实距离**：$dist[u][v] = dist'[u][v] - h[u] + h[v]$。

### 复杂度

- Bellman-Ford：$O(nm)$
- $n$ 次 Dijkstra（堆优化）：$O(n \cdot m \log n)$
- 总计：$O(nm \log n)$ —— 对稀疏图（$m \ll n^2$）优于 Floyd 的 $O(n^3)$

## 代码模板（稀疏图 APSP，含负权边）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

constexpr long long INF = 4e18;

struct Edge {
    int to;
    long long weight;
};

using Pair = std::pair<long long, int>;

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m;
    std::cin >> n >> m;

    std::vector<std::vector<Edge>> adj(n + 1);
    struct RawEdge { int u, v; long long w; };
    std::vector<RawEdge> raw_edges;
    raw_edges.reserve(m + n);

    for (int i = 0; i < m; i++) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        adj[u].push_back({v, w});
        raw_edges.push_back({u, v, w});
    }

    // 1. 添加虚拟源点 0，连向所有点，权 0
    for (int i = 1; i <= n; i++) {
        raw_edges.push_back({0, i, 0});
    }

    // 2. Bellman-Ford 求 h[v]
    std::vector<long long> h(n + 1, INF);
    h[0] = 0;
    for (int iter = 1; iter <= n; i++ter) {
        bool updated = false;
        for (const auto& e : raw_edges) {
            if (h[e.u] != INF && h[e.v] > h[e.u] + e.w) {
                h[e.v] = h[e.u] + e.w;  // 松弛
                updated = true;
            }
        }
        if (!updated) break;
        if (iter == n && updated) {
            std::cout << "存在负权环\n";  // 第 n 轮仍能松弛 => 有负权环
            return 0;
        }
    }

    // 3. 重新加权：建立新图 adj2（新权重 w' = w + h[u] - h[v] 保证非负）
    std::vector<std::vector<Edge>> adj2(n + 1);
    for (const auto& e : raw_edges) {
        if (e.u == 0) continue;  // 虚拟边不参与后续 Dijkstra
        long long new_w = e.w + h[e.u] - h[e.v];
        adj2[e.u].push_back({e.v, new_w});
    }

    // 4. 对每个点跑 Dijkstra（惰性删除：堆里留旧记录，pop 时 vis 跳过）
    std::vector<std::vector<long long>> dist(n + 1, std::vector<long long>(n + 1, INF));

    for (int s = 1; s <= n; ++s) {
        std::vector<long long>& d = dist[s];
        std::vector<bool> vis(n + 1, false);
        std::priority_queue<Pair, std::vector<Pair>, std::greater<>> pq;

        d[s] = 0;
        pq.emplace(0, s);

        while (!pq.empty()) {
            auto [du, u] = pq.top(); pq.pop();
            if (vis[u]) continue;  // 惰性删除：过时记录直接丢弃
            vis[u] = true;

            for (const auto& e : adj2[u]) {
                int v = e.to;
                long long w = e.weight;
                if (!vis[v] && d[v] > du + w) {
                    d[v] = du + w;  // 松弛
                    pq.emplace(d[v], v);
                }
            }
        }

        // 5. 还原真实距离
        for (int v = 1; v <= n; ++v) {
            if (d[v] != INF) d[v] = d[v] - h[s] + h[v];
        }
    }

    // 输出所有点对距离
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (dist[i][j] == INF) std::cout << "INF ";
            else std::cout << dist[i][j] << ' ';
        }
        std::cout << '\n';
    }
    return 0;
}
```

# 四大算法复杂度与适用场景总结

| 算法                | 问题类型 | 边权限制       | 时间复杂度     | 空间复杂度 | 核心适用场景                             |
| ------------------- | -------- | -------------- | -------------- | ---------- | ---------------------------------------- |
| **Floyd-Warshall**  | APSP     | 任意（无负环） | $O(n^3)$       | $O(n^2)$   | $n \le 400$ 稠密图、需路径重构、传递闭包 |
| **Bellman-Ford**    | SSSP     | 任意（可负）   | $O(nm)$        | $O(n+m)$   | 含负权边、需检测负环、差分约束           |
| **Dijkstra (堆)**   | SSSP     | **非负**       | $O(m \log n)$  | $O(n+m)$   | 非负权单源最短路、通用首选               |
| **Dijkstra (矩阵)** | SSSP     | **非负**       | $O(n^2)$       | $O(n^2)$   | 稠密图（$m \approx n^2$）                |
| **Johnson**         | APSP     | 任意（无负环） | $O(nm \log n)$ | $O(n+m)$   | 稀疏图 APSP 含负权边                     |
