# 最短路径

在带权有向图 $G=(V,E)$ 中，给定源点 $s$，求 $s$ 到其余各点的最短路径长度（单源最短路径，SSSP）；或求任意两点间的最短路径长度（多源最短路径，APSP）。边权可为正、负，但**不允许存在负权环**（否则最短路无定义）。

记 $|V|=n$，$|E|=m$。

---

# Floyd-Warshall 算法

Floyd-Warshall 算法是一种**动态规划**算法，用于求解**所有点对最短路径**（APSP）。它的核心思想是：逐步允许使用编号为 $1..k$ 的点作为中间点，更新任意两点间的最短距离。

## 算法原理

设 $dist[i][j]^{(k)}$ 表示只允许使用 $\{1,2,\dots,k\}$ 作为中间点时，$i$ 到 $j$ 的最短距离。则有递推式：

$$
dist[i][j]^{(k)} = \min\bigl(dist[i][j]^{(k-1)},\; dist[i][k]^{(k-1)} + dist[k][j]^{(k-1)}\bigr)
$$

初始时 $dist[i][j]^{(0)}$ 为邻接矩阵（无边设为 $\infty$，自环为 $0$）。最终 $dist[i][j]^{(n)}$ 即为答案。

## 实现步骤

1. 初始化 $n \times n$ 距离矩阵：$dist[i][j] = w(i,j)$（无边设 $\infty$，$i=j$ 设 $0$）。
2. 三重循环 $k=1..n$，$i=1..n$，$j=1..n$，执行松弛操作。
3. （可选）记录 `next[i][j]` 用于**路径重构**。

## 复杂度

- 时间：$O(n^3)$
- 空间：$O(n^2)$（可压缩为原地更新）

## 代码模板（P3371 【模板】多源最短路径）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

constexpr long long INF = 4e18;

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m;
    std::cin >> n >> m;

    std::vector<std::vector<long long>> dist(n + 1, std::vector<long long>(n + 1, INF));
    for (int i = 1; i <= n; ++i) dist[i][i] = 0;

    for (int i = 0; i < m; ++i) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        dist[u][v] = std::min(dist[u][v], w);  // 可能有重边，取最小
    }

    // Floyd-Warshall 核心三重循环
    for (int k = 1; k <= n; ++k) {
        for (int i = 1; i <= n; ++i) {
            if (dist[i][k] == INF) continue;  // 微优化：不可达则跳过
            for (int j = 1; j <= n; ++j) {
                if (dist[k][j] == INF) continue;
                if (dist[i][j] > dist[i][k] + dist[k][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }

    // 输出或判断负环
    for (int i = 1; i <= n; ++i) {
        if (dist[i][i] < 0) {
            std::cout << "存在负权环\n";
            return 0;
        }
    }

    // 示例：输出所有点对距离
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (dist[i][j] == INF) std::cout << "INF ";
            else std::cout << dist[i][j] << ' ';
        }
        std::cout << '\n';
    }
    return 0;
}
```

# Bellman-Ford 算法

Bellman-Ford 算法用于**单源最短路径**，支持**负权边**，并能**检测负权环**。核心思想是**边松弛**：对所有边执行 $n-1$ 轮松弛，第 $n$ 轮若仍能松弛则存在负权环。

## 算法原理

最短路至多包含 $n-1$ 条边。对所有边执行 $n-1$ 次松弛：

$$
\text{if } dist[v] > dist[u] + w(u,v) \text{ then } dist[v] = dist[u] + w(u,v)
$$

第 $n$ 次松弛若仍有更新，说明存在从源点可达的负权环。

## 实现步骤

1. 初始化 $dist[s]=0$，其余 $=\infty$。
2. 重复 $n-1$ 次：遍历所有边，执行松弛。
3. 第 $n$ 次遍历：若仍有边可松弛，标记其终点为“受负环影响”。
4. （可选）从受影响点出发 DFS/BFS，标记所有可达点为 $-\infty$。

## 复杂度

- 时间：$O(nm)$
- 空间：$O(n+m)$

## 优化：SPFA（Shortest Path Faster Algorithm）

SPFA 是 Bellman-Ford 的队列优化版本，**仅将“距离被更新的点”入队**，平均情况下极快，但**最坏仍为 $O(nm)$**，且易被卡数据（构造长链反复入队）。竞赛中**慎用**，或加入 SLF/LLL 优化、计数判负环。

## 代码模板（P3385 【模板】负权最短路径 / 负环检测）

```cpp
#include <iostream>
#include <vector>
#include <queue>

constexpr long long INF = 4e18;

struct Edge {
    int from, to;
    long long weight;
};

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m, s;
    std::cin >> n >> m >> s;

    std::vector<Edge> edges;
    edges.reserve(m);
    std::vector<std::vector<int>> adj(n + 1);  // 用于负环传播

    for (int i = 0; i < m; ++i) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        edges.push_back({u, v, w});
        adj[u].push_back(v);
    }

    std::vector<long long> dist(n + 1, INF);
    dist[s] = 0;

    // 1. 标准 Bellman-Ford：n-1 轮松弛
    for (int iter = 1; iter <= n - 1; ++iter) {
        bool updated = false;
        for (const auto& e : edges) {
            if (dist[e.from] != INF && dist[e.to] > dist[e.from] + e.weight) {
                dist[e.to] = dist[e.from] + e.weight;
                updated = true;
            }
        }
        if (!updated) break;  // 提前终止
    }

    // 2. 第 n 轮检测负环，标记受影响的点
    std::vector<bool> in_neg_cycle(n + 1, false);
    for (const auto& e : edges) {
        if (dist[e.from] != INF && dist[e.to] > dist[e.from] + e.weight) {
            in_neg_cycle[e.to] = true;
        }
    }

    // 3. 从负环点出发 BFS，标记所有可达点为 -INF
    std::queue<int> q;
    for (int i = 1; i <= n; ++i) {
        if (in_neg_cycle[i]) q.push(i);
    }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        dist[u] = -INF;
        for (int v : adj[u]) {
            if (!in_neg_cycle[v]) {
                in_neg_cycle[v] = true;
                q.push(v);
            }
        }
    }

    // 4. 输出
    for (int i = 1; i <= n; ++i) {
        if (dist[i] == INF) std::cout << "INF\n";
        else if (dist[i] == -INF) std::cout << "-INF\n";
        else std::cout << dist[i] << '\n';
    }
    return 0;
}
```

# Dijkstra 算法

Dijkstra 算法是**非负权边**单源最短路径的**贪心**算法。每次从“未确定最短距离的点”中取出距离最小的点，确定其最短距离，并用它松弛出边。

## 算法原理

维护集合 $S$（已确定最短距离的点）。每步从 $V \setminus S$ 中取 $dist$ 最小的点 $u$ 加入 $S$，对 $u$ 的出边松弛。正确性依赖于**非负权边**：一旦 $u$ 被取出，其 $dist[u]$ 不会再被更短路径更新。

## 实现方式与复杂度对比

| 实现方式            | extract-min      | decrease-key / 松弛方式    | 总复杂度          | 适用场景                  |
| ------------------- | ---------------- | -------------------------- | ----------------- | ------------------------- |
| 邻接矩阵 + 线性扫描 | $O(n)$           | $O(1)$ 直接改数组          | $O(n^2)$          | 稠密图（$m \approx n^2$） |
| 邻接表 + 二叉堆     | $O(\log n)$      | 惰性删除（重复入堆）       | $O(m \log n)$     | 稀疏图，通用首选          |
| 邻接表 + 斐波那契堆 | $O(\log n)$ 均摊 | $O(1)$ 均摊真 decrease-key | $O(m + n \log n)$ | 理论最优，工程少用        |

> **注意**：C++ `priority_queue` 无原生 decrease-key，常用**惰性删除**——松弛时直接 `push` 新记录，取出时若该点已访问则 `continue`。堆大小 $O(m)$，复杂度 $O(m \log m) = O(m \log n)$。

## 代码模板 1：邻接表 + 最小堆（P3371 / P4779 单源最短路径）

```cpp
#include <iostream>
#include <vector>
#include <queue>

constexpr long long INF = 4e18;

struct Edge {
    int to;
    long long weight;
};

using Pair = std::pair<long long, int>;  // {dist, vertex}

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m, s;
    std::cin >> n >> m >> s;

    std::vector<std::vector<Edge>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        adj[u].push_back({v, w});
    }

    std::vector<long long> dist(n + 1, INF);
    std::vector<bool> vis(n + 1, false);
    std::priority_queue<Pair, std::vector<Pair>, std::greater<>> pq;

    dist[s] = 0;
    pq.emplace(0, s);

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (vis[u]) continue;          // 惰性删除：过时记录
        vis[u] = true;

        for (const auto& e : adj[u]) {
            int v = e.to;
            long long w = e.weight;
            if (!vis[v] && dist[v] > d + w) {
                dist[v] = d + w;
                pq.emplace(dist[v], v);
            }
        }
    }

    for (int i = 1; i <= n; ++i) {
        if (dist[i] == INF) std::cout << "INF ";
        else std::cout << dist[i] << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

## 代码模板 2：邻接矩阵版（稠密图，P3371 当 $n \le 2000$ 时）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

constexpr long long INF = 4e18;

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m, s;
    std::cin >> n >> m >> s;

    std::vector<std::vector<long long>> g(n + 1, std::vector<long long>(n + 1, INF));
    for (int i = 1; i <= n; ++i) g[i][i] = 0;

    for (int i = 0; i < m; ++i) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        g[u][v] = std::min(g[u][v], w);
    }

    std::vector<long long> dist(n + 1, INF);
    std::vector<bool> vis(n + 1, false);
    dist[s] = 0;

    for (int iter = 1; iter <= n; ++iter) {
        // 线性扫描找未访问的最小 dist
        int u = -1;
        for (int i = 1; i <= n; ++i) {
            if (!vis[i] && (u == -1 || dist[i] < dist[u])) u = i;
        }
        if (u == -1 || dist[u] == INF) break;
        vis[u] = true;

        // 松弛 u 的所有出边
        for (int v = 1; v <= n; ++v) {
            if (!vis[v] && g[u][v] != INF && dist[v] > dist[u] + g[u][v]) {
                dist[v] = dist[u] + g[u][v];
            }
        }
    }

    for (int i = 1; i <= n; ++i) {
        if (dist[i] == INF) std::cout << "INF ";
        else std::cout << dist[i] << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

# Johnson 算法

Johnson 算法用于**稀疏图的所有点对最短路径（APSP）**。核心思想：**重新加权**消除负权边，然后对每个点跑一次 Dijkstra。

## 算法步骤

1. **添加虚拟源点** $s'$，向所有点连权为 $0$ 的边。
2. 跑 **Bellman-Ford** 从 $s'$ 求 $h[v] = \delta(s', v)$。若有负环，直接报告。
3. **重新加权**：每条边 $(u,v,w)$ 新权重 $w' = w + h[u] - h[v]$。可证 $w' \ge 0$，且任意路径长度仅相差常数 $h[t]-h[s]$，最短路结构不变。
4. 对每个点 $u=1..n$，跑 **Dijkstra**（用 $w'$）求 $dist'[u][v]$。
5. **还原真实距离**：$dist[u][v] = dist'[u][v] - h[u] + h[v]$。

## 复杂度

- Bellman-Ford：$O(nm)$
- $n$ 次 Dijkstra（堆优化）：$O(n \cdot m \log n)$
- 总计：$O(nm \log n)$ —— 对稀疏图（$m \ll n^2$）优于 Floyd 的 $O(n^3)$

## 代码模板（稀疏图 APSP，含负权边）

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

constexpr long long INF = 4e18;

struct Edge {
    int to;
    long long weight;
};

using Pair = std::pair<long long, int>;

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int n, m;
    std::cin >> n >> m;

    std::vector<std::vector<Edge>> adj(n + 1);
    struct RawEdge { int u, v; long long w; };
    std::vector<RawEdge> raw_edges;
    raw_edges.reserve(m + n);

    for (int i = 0; i < m; ++i) {
        int u, v;
        long long w;
        std::cin >> u >> v >> w;
        adj[u].push_back({v, w});
        raw_edges.push_back({u, v, w});
    }

    // 1. 添加虚拟源点 0，连向所有点，权 0
    for (int i = 1; i <= n; ++i) {
        raw_edges.push_back({0, i, 0});
    }

    // 2. Bellman-Ford 求 h[v]
    std::vector<long long> h(n + 1, INF);
    h[0] = 0;
    for (int iter = 1; iter <= n; ++iter) {
        bool updated = false;
        for (const auto& e : raw_edges) {
            if (h[e.u] != INF && h[e.v] > h[e.u] + e.w) {
                h[e.v] = h[e.u] + e.w;
                updated = true;
            }
        }
        if (!updated) break;
        if (iter == n && updated) {
            std::cout << "存在负权环\n";
            return 0;
        }
    }

    // 3. 重新加权：建立新图 adj2
    std::vector<std::vector<Edge>> adj2(n + 1);
    for (const auto& e : raw_edges) {
        if (e.u == 0) continue;  // 虚拟边不参与后续 Dijkstra
        long long new_w = e.w + h[e.u] - h[e.v];
        adj2[e.u].push_back({e.v, new_w});
    }

    // 4. 对每个点跑 Dijkstra
    std::vector<std::vector<long long>> dist(n + 1, std::vector<long long>(n + 1, INF));

    for (int s = 1; s <= n; ++s) {
        std::vector<long long>& d = dist[s];
        std::vector<bool> vis(n + 1, false);
        std::priority_queue<Pair, std::vector<Pair>, std::greater<>> pq;

        d[s] = 0;
        pq.emplace(0, s);

        while (!pq.empty()) {
            auto [du, u] = pq.top(); pq.pop();
            if (vis[u]) continue;
            vis[u] = true;

            for (const auto& e : adj2[u]) {
                int v = e.to;
                long long w = e.weight;
                if (!vis[v] && d[v] > du + w) {
                    d[v] = du + w;
                    pq.emplace(d[v], v);
                }
            }
        }

        // 5. 还原真实距离
        for (int v = 1; v <= n; ++v) {
            if (d[v] != INF) d[v] = d[v] - h[s] + h[v];
        }
    }

    // 输出所有点对距离
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (dist[i][j] == INF) std::cout << "INF ";
            else std::cout << dist[i][j] << ' ';
        }
        std::cout << '\n';
    }
    return 0;
}
```

# 四大算法复杂度与适用场景总结

| 算法                | 问题类型 | 边权限制       | 时间复杂度     | 空间复杂度 | 核心适用场景                             |
| ------------------- | -------- | -------------- | -------------- | ---------- | ---------------------------------------- |
| **Floyd-Warshall**  | APSP     | 任意（无负环） | $O(n^3)$       | $O(n^2)$   | $n \le 400$ 稠密图、需路径重构、传递闭包 |
| **Bellman-Ford**    | SSSP     | 任意（可负）   | $O(nm)$        | $O(n+m)$   | 含负权边、需检测负环、差分约束           |
| **Dijkstra (堆)**   | SSSP     | **非负**       | $O(m \log n)$  | $O(n+m)$   | 非负权单源最短路、通用首选               |
| **Dijkstra (矩阵)** | SSSP     | **非负**       | $O(n^2)$       | $O(n^2)$   | 稠密图（$m \approx n^2$）                |
| **Johnson**         | APSP     | 任意（无负环） | $O(nm \log n)$ | $O(n+m)$   | 稀疏图 APSP 含负权边                     |
