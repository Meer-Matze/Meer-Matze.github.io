# 最小生成树

无向连通图的**最小生成树**（Minimum Spanning Tree，MST）为边权和最小的生成树。最小生成树是图论中的一个重要概念，广泛应用于网络设计、聚类分析等领域。

记 $|V|=n$，$|E|=m$。

# Kruskal 算法

Kruskal 算法是一种贪心算法，它按照边的权值从小到大依次考虑每条边，如果这条边不会在当前的生成树中形成环，就将它加入到生成树中。这个过程一直持续到生成树包含了所有的顶点为止。

## Kruskal 算法的实现步骤如下：

1. 将图中的所有边按权值从小到大排序。
2. 初始化一个空的生成树。
3. 遍历排序后的边列表，对于每条边，检查它的两个顶点是否在同一个连通分量中。如果不在同一个连通分量中，则将这条边加入到生成树中，并将两个顶点所在的连通分量合并。
4. 重复步骤 3，直到生成树包含了所有的顶点为止。

## P1194 买礼物

又到了一年一度的明明生日了，明明想要买 $B$ 样东西，巧的是，这 $B$ 样东西价格都是 $A$ 元。

但是，商店老板说最近有促销活动，也就是：

如果你买了第 $I$ 样东西，再买第 $J$ 样，那么就可以只花 $K_{I,J}$ 元，更巧的是，$K_{I,J}$ 竟然等于 $K_{J,I}$。

现在明明想知道，他最少要花多少钱。

**输入格式：**

第一行两个整数，$A,B$。

接下来 $B$ 行，每行 $B$ 个数，第 $I$ 行第 $J$ 个为 $K_{I,J}$。

我们保证 $K_{I,J}=K_{J,I}$ 并且 $K_{I,I}=0$。

特别的，如果 $K_{I,J}=0$，那么表示这两样东西之间不会导致优惠。

注意 $K_{I,J}$ **可能大于** $A$。

**输出格式：**

一个整数，为最小要花的钱数。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

/*
 * P1194 买礼物 —— 最小生成树(Kruskal)
 *
 * 核心思想：
 *   每样东西原价都是 A 元，买第 I 样后再买第 J 样可以只花 K[I][J] 元。
 *   把"原价 A 元买"抽象成一条从"商店"(虚拟点 0)连到该物品、权值为 A 的边；
 *   两个物品之间有优惠，就连一条权值为 K 的边。
 *   这样"买齐所有东西的最小花费"就等价于
 *   "包含点 0..B 的最小生成树的总权值"。
 */

int a, b;               // a：原价；b：物品数量
int vertex[501];        // 并查集父节点数组。点编号 0..b（0 是虚拟的"商店"），
                        // 共 b+1 个点，所以至少开 501 大小（b 最大 500）

struct Edge{
    int from;           // 边的起点
    int to;             // 边的终点
    int cost;           // 边的权值（买 to 时只花 cost 元）
};

std::vector<Edge> edges;    // 存储所有候选边

// 并查集查找：返回 x 所在集合的代表元（根节点）
int find(int x){
    while(vertex[x] != x){              // 一直向上找父节点，直到根（父节点是自己）
        vertex[x] = vertex[vertex[x]];  // 路径压缩：把 x 直接指向爷爷节点，
                                        // 下次查找更快
        x = vertex[x];
    }
    return x;
}

int main() {
    // 1. 读入原价 A 和物品数量 B
    std::cin >> a >> b;

    // 2. 读入优惠矩阵 K[1..B][1..B]，把有效的优惠转成边
    for(int i = 1; i <= b; i++){
        for(int j = 1; j <= b; j++){
            int discounts;
            std::cin >> discounts;
            if(discounts != 0){          // 关键：K 为 0 表示"这两个物品之间没有优惠"，
                edges.push_back({i, j, discounts});
            }
        }
    }

    // 3. 添加"原价买"的边：从虚拟点 0（商店）到每个物品，权值为 A
    for(int i = 1; i <= b; i++){
        edges.push_back({0, i, a});
    }

    // 4. Kruskal 第一步：把所有边按权值从小到大排序
    std::sort(edges.begin(), edges.end(), [](const Edge& x, const Edge& y){return x.cost < y.cost;});

    // 5. 初始化并查集：每个点自成一个集合（父节点是自己）
    for(int i = 0; i <= b; i++) vertex[i] = i;

    // 6. Kruskal 第二步：从小到大依次尝试每条边，不成环就选它
    int ans = 0;    // 累计最小花费
    int cnt = 0;    // 已选中的边数
    for(const Edge& e : edges){
        int fx = find(e.from);      // e.from 所在集合
        int fy = find(e.to);        // e.to   所在集合
        if(fx != fy){               // 两个端点不在同一集合 -> 连上不会成环
            vertex[fx] = fy;        // 合并两个集合（把 fx 的根指向 fy）
            ans += e.cost;          // 把这条边的花费计入答案
            if(++cnt == b) break;   // 连通 b+1 个点只需要 b 条边，选够了就结束
        }
    }

    // 7. 输出最小花费
    std::cout << ans << std::endl;
    return 0;
}
```

# Prims 算法

Prims 算法也是一种贪心算法，它从任意一个顶点开始，每次选择一条连接当前生成树和剩余顶点的最小权值边，并将其加入到生成树中。这个过程一直持续到生成树包含了所有的顶点为止。

## Prims 算法的实现步骤如下：

1. 从任意一个顶点开始，将其加入到生成树中。
2. 在当前生成树和剩余顶点之间，选择一条权值最小的边，并将其加入到生成树中。
3. 重复步骤 2，直到生成树包含了所有的顶点为止。

Prim 的实现方式取决于"如何取出当前最小边"这一步用什么数据结构，从简单到复杂依次为：邻接矩阵、邻接表+二叉堆、邻接表+斐波那契堆。三者的核心区别在于 **extract-min** 与 **decrease-key** 两个操作的复杂度：

| 实现方式            | extract-min        | decrease-key                                 | 总复杂度         |
| ------------------- | ------------------ | -------------------------------------------- | ---------------- |
| 邻接矩阵            | $O(n)$（线性扫描） | $O(1)$（直接改数组）                         | $O(n^2)$         |
| 邻接表 + 二叉堆     | $O(\log n)$        | 无真正 decrease-key，改用"重复入堆+惰性删除" | $O(m\log n)$     |
| 邻接表 + 斐波那契堆 | $O(\log n)$ 均摊   | $O(1)$ 均摊                                  | $O(m + n\log n)$ |

## 邻接矩阵实现（P1194 买礼物）

本题物品之间两两可能有优惠边，图接近完全图（稠密），适合用**邻接矩阵版 Prim**，复杂度 $O(n^2)$。思路与 Kruskal 一致：虚拟点 0 代表商店，权值为 $A$ 的边连向每个物品。

```cpp
#include <iostream>
#include <vector>

/*
 * P1194 买礼物 —— 最小生成树 (Prim, 邻接矩阵)
 *
 * 核心思想：
 *   与 Kruskal 版本相同，把"原价 A 元买"抽象成虚拟点 0（商店）到每个物品、
 *   权值为 A 的边；两个物品间有优惠则连一条权值为 K 的边。
 *   Prim 算法从虚拟点 0 出发，每次选择"距离当前生成树最近的未加入点"，
 *   逐步扩展生成树，直到覆盖全部 B+1 个点。
 *   本题物品间两两可能有边（近似完全图，边数 O(B^2)），
 *   适合用邻接矩阵实现，复杂度 O(N^2)，优于稀疏图专用的堆优化版本。
 */

constexpr int k_infinity = 2147483647;

int b;                                              // 物品数量 B
int total_point_count;                              // 总点数 = B + 1（含虚拟商店 0）
std::vector<std::vector<int>> adjacency_matrix;     // adjacency_matrix[i][j]：i-j 边权，不存在为 k_infinity
std::vector<int> min_distance;                      // min_distance[i]：点 i 到当前生成树的最短距离
std::vector<bool> is_join;                          // is_join[i]：点 i 是否已加入生成树

// 用邻接矩阵版 Prim 求最小生成树的总权值
int Prim() {
    min_distance.assign(total_point_count, k_infinity);
    is_join.assign(total_point_count, false);
    min_distance[0] = 0;                            // 从虚拟商店（点 0）出发

    int ans = 0;
    for (int i = 0; i < total_point_count; i++) {
        // 1. 在未加入生成树的点中，找到距离生成树最近的一个
        int nearest_vertex = -1;
        for (int j = 0; j < total_point_count; ++j) {
            if (!is_join[j] &&
                (nearest_vertex == -1 || min_distance[j] < min_distance[nearest_vertex])) {
                nearest_vertex = j;
            }
        }

        // 2. 将该点加入生成树，累加其接入代价
        is_join[nearest_vertex] = true;
        ans += min_distance[nearest_vertex];

        // 3. 用新加入的点更新其余点到生成树的距离
        for (int j = 0; j < total_point_count; ++j) {
            if (!is_join[j] && adjacency_matrix[nearest_vertex][j] < min_distance[j]) {
                min_distance[j] = adjacency_matrix[nearest_vertex][j];
            }
        }
    }
    return ans;
}

int main() {
    // 1. 读入原价 A 和物品数量 B
    int a;
    std::cin >> a >> b;
    total_point_count = b + 1;

    // 2. 初始化邻接矩阵，默认所有点之间不连通
    adjacency_matrix.assign(total_point_count, std::vector<int>(total_point_count, k_infinity));

    // 3. 读入优惠矩阵 K[1..B][1..B]，把有效的优惠转成边（K=0 表示无优惠）
    for (int i = 1; i <= b; ++i) {
        for (int j = 1; j <= b; ++j) {
            int discount;
            std::cin >> discount;
            if (discount != 0 && discount < adjacency_matrix[i][j]) {
                adjacency_matrix[i][j] = discount;
            }
        }
    }

    // 4. 添加"原价买"的边：虚拟点 0（商店）到每个物品，权值为 A
    for (int i = 1; i <= b; ++i) {
        adjacency_matrix[0][i] = adjacency_matrix[i][0] = a;
    }

    // 5. 运行 Prim 算法并输出结果
    std::cout << Prim() << std::endl;
    return 0;
}
```

相比 Kruskal 的 $O(m\log m)$，当边数 $m$ 接近 $n^2$（本题即完全图）时，$O(n^2)$ 的 Prim 更优。

## 邻接表 + 最小堆实现（P3366）

用 `priority_queue` 实现的二叉堆没有原生的 decrease-key 操作，常见做法是：每次松弛都重新入堆一条新记录，取出时若该点已在树中（说明是过时记录）则跳过（惰性删除）。堆中最多有 $O(m)$ 条记录，故复杂度为 $O(m\log m) = O(m\log n)$。

```cpp
#include <iostream>
#include <vector>
#include <queue>

/*
 * P3366 【模板】最小生成树 —— Prim (邻接表 + 最小堆)
 *
 * 核心思想：
 *   std::priority_queue 不支持真正的 decrease-key，因此每次发现
 *   更短距离时直接重新入堆；取出堆顶时若该点已在生成树中，说明是
 *   过时记录，直接丢弃（惰性删除）。堆中记录数最多为 O(M)，
 *   总复杂度 O(M log M) = O(M log N)。
 */

constexpr int k_infinity = 2147483647;

struct Edge {
    int to;      // 边指向的点
    int weight;  // 边权
};

// {当前距离, 点编号}，用于最小堆；distance 小的优先
using DistanceNodePair = std::pair<int, int>;

int vertex_count, edge_count;                          // 点数 N，边数 M
std::vector<std::vector<Edge>> adjacency_list;         // adjacency_list[u]：从 u 出发的所有边
std::vector<int> min_distance;                         // min_distance[i]：点 i 到当前生成树的最短距离
std::vector<bool> is_join;                             // is_join[i]：点 i 是否已加入生成树

// 用邻接表 + 最小堆版 Prim 求最小生成树的总权值；若图不连通返回 -1
long long computeMinimumSpanningTreeWeight() {
    std::priority_queue<DistanceNodePair, std::vector<DistanceNodePair>, std::greater<>> min_heap;

    min_distance.assign(vertex_count + 1, k_infinity);
    is_join.assign(vertex_count + 1, false);
    min_distance[1] = 0;                               // 任取 1 号点作为起点
    min_heap.emplace(0, 1);

    long long total_weight = 0;
    int visited_count = 0;

    while (!min_heap.empty()) {
        auto [current_distance, current_vertex] = min_heap.top();
        min_heap.pop();

        if (is_join[current_vertex]) {                 // 过时记录，跳过
            continue;
        }

        is_join[current_vertex] = true;
        total_weight += current_distance;
        ++visited_count;

        for (const auto&[to, weight] : adjacency_list[current_vertex]) {
            if (!is_join[to] && weight < min_distance[to]) {
                min_distance[to] = weight;
                min_heap.emplace(weight, to);
            }
        }
    }

    return (visited_count == vertex_count) ? total_weight : -1;
}

int main() {
    std::cin >> vertex_count >> edge_count;
    adjacency_list.assign(vertex_count + 1, {});

    for (int i = 0; i < edge_count; ++i) {
        int from, to, weight;
        std::cin >> from >> to >> weight;
        adjacency_list[from].push_back({to, weight});
        adjacency_list[to].push_back({from, weight});
    }

    const long long result = computeMinimumSpanningTreeWeight();
    if (result == -1) {
        std::cout << "orz" << std::endl;
    } else {
        std::cout << result << std::endl;
    }
    return 0;
}
```

## 邻接表 + 斐波那契堆实现

理论最优的实现，但在实际中由于常数较大，通常不如最小堆快。同时代码复杂度高，且 C++ STL 没有现成的斐波那契堆实现，因此在竞赛中很少使用。

# Borůvka 算法

Borůvka 算法是一种基于分治思想的算法，它在每一步都选择连接两个不同连通分量的最小权值边，并将这些边加入到生成树中。这个过程一直持续到生成树包含了所有的顶点为止。

## Borůvka 算法的实现步骤如下：

1. 初始化每个顶点为一个独立的连通分量。
2. 对于每个连通分量，找到连接它和其他连通分量的最小权值边，并将这些边加入到生成树中。
3. 合并所有被连接的连通分量。
4. 重复步骤 2 和 3，直到生成树包含了所有的顶点为止。

## 三种算法的适用场景与复杂度对比

| 算法                      | 适用场景                                | 复杂度           |
| ------------------------- | --------------------------------------- | ---------------- |
| Kruskal                   | 边数适中、可整体排序                    | $O(m\log m)$     |
| Prim（邻接矩阵）          | 稠密图                                  | $O(n^2)$         |
| Prim（邻接表+最小堆）     | 稀疏图、可用堆优化                      | $O(m\log n)$     |
| Prim（邻接表+斐波那契堆） | 稀疏图、可用斐波那契堆优化              | $O(m + n\log n)$ |
| Borůvka                   | 稀疏图、并行/分治、Boruvka+DSU 优化场景 | $O(m\log n)$     |

# 次小生成树

设最小生成树为 MST，权值和为 $W$。

## 非严格次小生成树

**定义**：权值和 $\ge W$ 的生成树中，权值和最小的那一棵（若图中存在多棵 MST，非严格次小生成树的权值可以等于 $W$）。

**应用场景**：判断 MST 是否唯一；求“次优方案”且允许并列最优。

**求法要点**（实现与证明从略）：

1. 先求出一棵 MST，倍增维护树上任意两点路径的**最大边权**。
2. 枚举所有非树边 $(u,v,w)$：若替换掉 $u\to v$ 路径上的最大边，增量为 $w - \text{maxEdge}(u,v)$。
3. 取所有增量中的最小值，$W+\Delta_{\min}$ 即为答案。

## 严格次小生成树

**定义**：权值和 $> W$ 的生成树中，权值和最小的那一棵。

**与非严格版本的区别**：当替换边权恰好等于路径最大边权（增量为 0）时，必须改用路径上的**严格次大边**，否则会得到与 MST 相同的权值。

**求法要点**（实现与证明从略）：

1. 倍增同时维护路径最大边权与严格次大边权（次大 < 最大，避免和最大值相同）。
2. 枚举非树边，若 $w = \text{maxEdge}(u,v)$，改用 $\text{secondMaxEdge}(u,v)$ 计算增量，否则仍用 maxEdge。
3. 取所有合法增量中的最小值。

# 瓶颈生成树和最小瓶颈路

**定义**：使生成树中**最大边权最小**的生成树（关注单条边的最大值，而非边权和）。

**性质**：任意一棵最小生成树一定是瓶颈生成树（可用环切定理反证，证明从略），但瓶颈生成树不一定是最小生成树。

**最小瓶颈路**：无向图中，顶点 $u$ 到顶点 $v$ 的所有路径中，最大边权最小的那条路径。

**应用**：

- 求任意两点间的最小瓶颈路，等价于该两点在 MST（同时也是瓶颈生成树）上路径的最大边权。
- 典型例题：货车运输（求两点间路径最大载重的最小值上限）。
- 常用技巧：**Kruskal 重构树**
  - Kruskal 重构树中：
    - 每个叶子节点对应原图的一个顶点；
    - 非叶子节点对应原图中某次合并的两棵子树，其权值为合并时所选边的权值；
    - 任意两叶子节点的最近公共祖先（LCA）对应原图中两点间路径的最大边权。
